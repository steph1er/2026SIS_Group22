# MediaPipe Face Landmarker model

`face_landmarker.task` is Google's MediaPipe Face Landmarker v2 task bundle.
It is committed so a fresh checkout can run colour analysis without a separate
model download or a dependency on model hosting availability.

- Source: <https://storage.googleapis.com/mediapipe-assets/face_landmarker_v2.task>
- Size: 1,402,487 bytes (about 1.4 MB)
- SHA-256: `af23fc7c1ff21d034deaa2b7fc1d56bb670ce69a4cbdc9579b6f1afd680835f4`
- Project and license: <https://github.com/google-ai-edge/mediapipe> (Apache License 2.0)

The runtime path can be overridden with `FACE_LANDMARKER_MODEL_PATH` when a
deployment stores models outside the repository.
